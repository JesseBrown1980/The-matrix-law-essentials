# Conditional shadow decomposition and adaptive addressed replay

**Status:** exact finite counting identity, local integer-only P–NP experiments; new native companion test pending. This is a companion technique to [primitive joint-shadow replay](LAW-PRIMITIVE-JOINT-SHADOW-REPLAY-20261126.md), with no change to the existing numbered laws or Yang–Mills certificates.

Given a residual constraint function on binary addresses, after conditioning, decompose its clause-variable incidence graph. If components have disjoint variable sets and U denotes unconstrained bits, then the total count is 2^|U| times the product of component counts. Conditioning on a variable partitions the count into the sum of its two branches. These are exact finite sum/product identities. A witness for a positive branch or the union of independent positive component witnesses can be recovered by addressed replay and checked against the source. For nonnegative weighted factors the same reasoning applies to sums of products, with free-domain sizes and exact boundary compatibility retained. Counts and witnesses must be associated with the precise residual function and source; cache-key identity alone is meaningful only within its declared source context.

This is standard component caching and AND-OR search adapted to the shadow representation. Unlike a fixed ordered decision DAG, the next address may depend on the conditioned residual graph. The benefit is that conditioning can split initially connected constraints. There is no guarantee of polynomially many residual states on arbitrary input.

## Experimental evidence

[P–NP PR #71, exact ledger and source hashes](https://github.com/JesseBrown1980/P-NP/blob/d2792ded04be320e0ee753326e153a010f26a2b8/native/AUTOMATIC_SHADOW_REPLAY.md). Local audit of 30 connected independent-set counting graphs, up to 72 variables: fixed natural and reverse orders each 26/30 before state cap; graph-neighborhood and greedy frontier 30/30; adaptive separator and degree/component 30/30. Cheap adaptive uses 5,119 cached states versus 21,425 neighborhood, but neighborhood wins on paths. The expensive separator heuristic uses 5,550 states and 255,546 planning vertex visits versus 21,046 degree-candidate visits for the cheap policy. Unlike planning units must be kept separate. The local independent reference recurrences and subset-zeta transform check every completed count. 24 general CNF cases also match reference DPLL counts (16 SAT, 8 UNSAT); adaptive cache 224 versus fixed 434, with additional graph and occurrence scanning. This is not a runtime or optimized solver comparison. The native companion implements graph replay only; native acceptance pending. The historical Brown–Hilbert/Fischer backend was not invoked.

## Reusable acceptance rule

Preserve joint dependencies until an exact conditioning or factorization certificate allows separation. Cache each residual primitive only once per source and apply free-coordinate scales separately. Charge the cost of discovering splits and ordering, state construction and retained witnesses. Compare fixed and adaptive policies on held-out inputs, and verify reconstructed original assignments. Report exceeding the budget as HOLD, never UNSAT. The prior primitive-shadow gate has hosted PASS (P–NP run 45883347051). No general P=NP claim, no changes to the matrix verification pipeline.
